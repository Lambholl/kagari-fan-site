# 月夜场景说明

## 场景布局

- 地形与外围树林在游戏中整体放大 `6` 倍，绕 Y 轴旋转 `90°` 使缓坡朝向玩家出发的南侧，并对齐世界原点处的地面高度为 `14` 米。主树在导出阶段已按 `6` 倍比例缩放，加载时不再重复放大。
- 篝以世界原点为交互中心（纸面基准高度 `14.02` 米），面朝西南方向。巨大用纸尺寸为 `7 × 6` 米，完整落在椭圆台顶内，主树位于左后方约 `(-5.16, -5.40)` 米处。
- 剧情开场、自由漫步，以及被缎带斩杀、摔死或撞树后复活，都用同一个出生点 `(-49, 71.2)`：西南坡下的花海，离主树约 `88` 米，地面比山顶低约 `7` 米。朝向按原作的场景图定下，主树在画面左上，地球在右上；从这里有可以走上山顶的路。坐标、旋转与比例统一维护在 `src/world/scene-layout.js`。
- 地面上的黑白雏菊按固定随机种子在客户端成片生成，避开纸面外扩 `0.25` 米范围、主树周围 `0.9` 米半径和坡度较大的崖壁。分两片撒点，共用同一套疏密噪声，接在一起看不出分界：
  - 丘顶花海 `6.2` 万朵，以世界原点为中心，密度从 `28` 米起逐渐降低，`70` 至 `110` 米之间淡出到 0，花海不会停在两块地形的接缝上。山顶每平方米约 `6` 朵。
  - 出生点花海 `2.4` 万朵，以出生点身后约 `10` 米的 `(-54, 80)` 为中心、半径 `55` 米均匀撒点，外圈一半逐渐淡出。出生点附近每平方米约 `6` 朵，身后约 `4` 朵；丘顶花海在这里只剩每平方米约 `1` 朵，身后几乎没有花。

## 地面与行走

- `src/world/surface.js` 提取地形中朝上的三角面并按 `4` 米水平方格索引；上下重叠处取最高的交点，供玩家行走、雏菊贴地和纸面起伏共用。
- 每一步检查地面坡度与高度差，往上的陡坡挡住，斜向遇阻时尝试沿单个坐标轴滑动；主树树根周围 `2` 米与篝的裙摆区域另设圆形阻挡。
- 往下走出崖边（目标点比脚下低出台阶高度，或是往下的陡坡）时腾空下落：保持走出时的水平速度，不受操控；落在陡坡上就贴着坡面往下滑，落在可以走的地面上就着地，按落地速度播放闷响。着地处比起跳点低出 `4` 米即算摔死：主角躺倒在地，视线慢慢转向夜空，画面褪色后作为彩蛋播放主角的独白，再黑屏回到出生点。掉出地形网格、下落 `80` 米仍没有地面时同样算摔死。摔死与缎带斩杀分开计数，不推进剧情。第一次摔死有完整独白，之后轮流播放三段短独白。
- 奔跑时撞进主树树根范围，且朝树心方向的速度超过 `3.8` 米/秒（奔跑 `5` 米/秒，与正面夹角约 40° 以内）时算撞死；斜着擦过或走路撞上只会被挡住。撞死时播放木头闷响和倒地声，之后与摔死相同：躺倒、看向夜空、播放独白，再回到出生点。撞树有自己的一套独白和计数。躺倒期间不能移动，也不能转动视角。

## 地面材质

- 烘焙贴图分辨率低（主平台 `4096` 像素约合 `8` 厘米一像素，远处地面 `1024` 像素约合 `2` 米一像素），放大后有方形色块和模糊条纹，只用来找主平台上岩石的位置；草地和岩石的颜色全部在 `src/world/ground-material.js` 里程序生成，均值分别取烘焙贴图中草地和岩石的平均颜色。主平台与远处地面共用同一套色板，近处平台和远处地形的草色一致。
- 远处的大片明暗和色调来自着色器里计算的非周期值噪声（四层，周期 `83`、`31`、`12`、`4.7` 米，每层旋转不同角度）。每层周期小于约 4 个像素时淡出到均值，走动时不闪烁；格点哈希不重复，五次插值没有格线。远处地面在 `350` 至 `800` 米之间平滑变暗到 `35%`，对应烘焙贴图原有的明暗。
- 近处草地在此之上叠加加载时生成的 `512 × 512` 无缝细节贴图：草叶颗粒（平铺 `1.25` 米）和成团起伏。所有采样都用哈希偏移，按低频噪声在两套随机平移之间过渡，看不出平铺周期。两者按单个像素覆盖的地面宽度淡出，分别在约 `1.5` 厘米和 `10` 厘米时完全消失。
  - 成团起伏按约 `5.3` 米和 `14` 米两种平铺尺寸、两个角度各采样一次再叠加。只用一种尺寸时团块大小一致，放大看远处时很规律。
  - 贴图里的噪声在加载时按频谱合成：每个频率取随机相位，再用快速傅里叶变换转回平面，没有格点。值噪声在格点处坡度为 0，多层格点互相对齐，凹凸光照下会出现规则排列的平点和小坑。成团起伏的振幅与频率的平方成反比，约 4 个周期以下截掉。
  - 贴图存成半浮点，mipmap 在 CPU 上逐级生成。8 位精度存高度时缓坡上会出现台阶，凹凸光照沿等高线画出环纹。生成整张贴图在电脑上约需 0.4 秒。
- 主平台按烘焙贴图的绿色程度区分岩石，中间值是长苔藓的岩石；远处地面不区分岩石。岩面纹理不用贴图，按世界坐标计算五层脊状三维值噪声（周期 `5` 米到约 `0.2` 米），不重复，也不需要投影。竖直方向频率乘 `1.6`，崖壁上拉成水平岩层；周期小于约 4 个像素的层淡出。
- 细节起伏用相邻像素位置重新采样的高度差扰动法线；直接对高度求屏幕导数会在斜看崖壁时出现细密横纹。
- 草地起伏用 Toksvig 法补偿画不出来的坡度：近处凹凸光照下法线朝向不一，平均亮度比平地低；远处起伏被 mipmap 过滤或淡出后，原本会按平地着色而偏亮。生成细节贴图时记下每层的坡度方差和每级 mipmap 保留的比例，着色器按相邻像素在地面上的距离估算丢掉的方差 σ²，把法线缩短到 `1/sqrt(1+σ²)`，并相应加大粗糙度。草叶颗粒的坡度均方根约 `0.75`，起伏画不出来后亮度最多降低约 20%，所以脚下约 3 米以外的地面整体偏暗；成团起伏坡度小，几乎不影响亮度。岩面不做补偿。
- 两块地形导出时的自发光和法线贴图强度不同，加载时统一取主平台的值。
- 主平台边缘压在远处地面上，两块网格的顶点不重合，顶点法线也不同，接缝处会出现一条明暗线。加载时在主平台贴着远处地面的边界两侧 `6` 米内，把两块网格的顶点法线都换成由可见地面高度差分得到的法线，再往外到 `20` 米逐渐恢复原法线；崖壁顶点不处理。

## 画面呈现与抗锯齿

- **Windows 呈现与像素上限**：Windows 平台在每帧渲染完成后将 WebGL 帧复制到不透明的二维画布显示，避免浏览器直接合成实时 WebGL 图层出现黑块。二维画布模式渲染像素上限为 `1920 × 1080`，直接显示 WebGL 模式上限为 `2560 × 1440`，同时保持窗口宽高比。开发模式下加 `?present=webgl` 可直接看 WebGL 画布。
- **异常值清理**：加载主树时将零长度或非有限顶点切线修复为垂直于法线的单位向量；后处理泛光前清零 `NaN` 与无穷大像素并限制高光上限，防止局部着色异常经模糊扩散成黑块。
- **抗锯齿设置**：点击画面右上角齿轮可切换抗锯齿（鼠标锁定时先按 `Esc`），选择保存在本地存储中：
  - **快捷（FXAA）**（默认）：输出后做单帧快速边缘平滑。
  - **精细（SMAA）**：单帧边缘检测与混合。
  - **稳像（TAA）**：每帧做 8 点像素内采样偏移，按上一帧视角与线性深度重投影对齐。天空平移时仅按旋转对齐历史，近处随镜头移动的手持物按深度淡出历史权重；快速转头、缩改窗口或切镜头时清空历史。
  - **关闭**：关闭抗锯齿后处理。
- **视场角**：设置面板的视场角滑条取 `50°` 至 `90°`（默认 `62°`），是横屏时的竖直视场角，保存在本地存储中；竖屏画面窄，在设置值上再加 `14°`。调整时清空 TAA 历史帧。设置只作用于游戏中，主界面用机位自带的视场角。
- **主界面机位**：固定机位，位置相对篝脚下的纸面中心，定义在 `src/main.js` 的 `TITLE_SHOTS`。宽高比大于 `1.25` 时用宽屏机位：篝左前方约 `2.7` 米、比纸面高 `0.45` 米，竖直视场角 `46°`，篝在画面右半边，地球在她右上方，左半边留给标题。其余用窄屏机位：约 `3` 米远、高 `0.6` 米，竖直视场角 `64°`，篝在画面上半部，下半部留给标题文字，地球在画面外。主界面上篝转到 `-120°`（游戏中为 `-40°`）：以机位到她的连线为轴左右镜像平时的朝向，仍以斜侧角对着镜头，脸朝画面左侧；手边的补光跟着转。进出主界面时清空 TAA 历史帧。
- **按住放大**：电脑上按住 `X` 放大到 `3` 倍，按住时滚轮每格调整 2 的 1/4 次方，范围 `1.25` 至 `8` 倍，松开恢复。8 倍时默认 `62°` 视场角收窄到约 `8.6°`。放大时视角灵敏度除以倍率，准星在画面上移动的速度不变；雏菊和光点按放大后的投影换算像素大小，立体花朵会在更远处出现。剧情接管镜头或窗口失去焦点时自动松开。
- **全屏**：触屏设备（`pointer: coarse` 或发生过触摸）且浏览器支持网页全屏时，右上角显示全屏按钮，再点一次退出。iPhone 上的 Safari 不支持网页全屏，不显示该按钮。
- **缎带**：篝手腕垂下的缎带是逐帧重建的条带网格，暗红到朱红的顶点色；模型手腕上缠的缎带（`Ribbon | crimson wraps`）取这两种红色的中间色。两者共用暖灰卡通着色（`ribbon`），保持原本的红色。倒竖时宽度沿长度连续收成尖刃，相邻顶点只隔约 `1.5` 厘米，逐顶点交替宽窄会连成方块状锯齿。飘动用两层值噪声生成：每条长尾有自己的噪声种子和 `0.8` 至 `1.25` 倍的节奏，扬起方向、高度和伸展长度各自缓慢漂移。所有缎带共用一路约 `0.6` 至 `1.4` 倍的阵风强度，倒竖时飘动幅度降到四成。
- **斩击判定**：剧情开场阶段在主角踩上纸面时斩击，第一次靠近也一样。纸是 `7×6` 米的斜放矩形，篝偏离中心，到四边距离在 `2.2` 至 `4` 米之间。纸边停留观察按到纸张外缘不足 `0.9` 米判断。
- **篝的头部**：平时低头约 `30°` 看纸（颈部分担约一半），每隔 `1.5` 至 `4` 秒随机换一个小幅偏移（左右 `±9°`、前后 `±5°`、歪头 `±3°`）再缓慢转过去。剧情开场阶段主角走近到 `11` 米时缎带先浮起，到 `7` 米她才抬头看向主角；抬头时摆头随之淡出。她只在主角位于身前半边（偏离正前方约 `90°` 以内，进出各留 `5°` 余量）时抬头，主角在身后时始终低头看纸。纸边交互提示按 `±118°` 判断。
- **远景花草与光点**：雏菊按花盘屏幕投影大小过渡：远景先绘制扩大后按原投影面积减淡的软边圆盘，近处再恢复立体花瓣并按宽度淡入细茎，斜看花盘时更晚切回立体花瓣，同时减小远景风摆幅度。软边圆盘一遍绘制全部花朵；立体花朵一遍只绘制镜头附近的花：花朵按 `8` 米水平方格分组，按最大花盘、当前投影和画面角落的视角算出立体花瓣还可能超过 `3` 像素的距离，镜头每水平移动 `2` 米或窗口变化时重新挑选。站在山顶时约 `1` 万朵进入立体花朵一遍（全部约 `8.6` 万朵），远处的花只在软边圆盘一遍里绘制。纸上飘浮的细小光点同样限制最小像素尺寸并按面积比例减淡，避免亚像素闪烁。

## 天空与极光

- 封闭球面天穹随相机移动：地平线附近按圆柱投影映射无极光全景图，向上平滑过渡到天顶夜色。极光、星空、银白月轮与地平线云同步响应剧情中的时间加速。
- 天上的“月亮”实为地球，场景设在月球南极附近。月面真北在世界坐标中从 `-z` 向东偏 `82°`（`LUNAR_NORTH_AZIMUTH`），地球在真北偏东 `16°`、仰角 `25°`，从出生点看在主树右上方。调整地球在画面中的位置时转动这个方位定义，地球相对真北的方位保持固定，观测点纬度、地球的倾斜和可见面都不变。修改方向后运行 `node scripts/calculate-earth-view.js` 检查朝向和贴图覆盖。

原始 `.blend` 文件与导出中间文件存放在 Git 忽略的 `.materials/`，网页从 `public/models/` 和 `public/textures/` 加载（构建时复制到 `dist/models/` 和 `dist/textures/`）：

主树数据记录在 `.materials/moonlit-scene/integration/source-tree/game-triangles.json`（电脑档树皮 `71,663` 面 + 叶片 `16,310` 面；手机档树皮 `64,448` 面 + 叶片 `11,514` 面）。移动优化版地形与树林模型归档于 `.materials/moonlit-scene/archive/`。重新导出步骤（在项目根目录运行）：

1. 导出主树中间模型（焊合树皮重合点、接回 `2` 根断枝并封合 `15` 处地面以上开口，按档位抽稀叶片并简化外围树冠）：

   ```sh
   blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python scripts/export-scene-tree.py
   ```

2. 打包场景模型到 `public/models/` 与夜空贴图到 `public/textures/`（需要带 WebP 支持的 Pillow；颜色贴图使用质量 `90` 的有损 WebP，法线等数据贴图使用无损 WebP）：

   ```sh
   python scripts/pack-scene-webp.py
   ```

角色模型导出命令见 [public/models/SOURCES.md](../public/models/SOURCES.md)。

## 运行与调试

```sh
pnpm dev
pnpm build
```

开发模式下支持以下 URL 参数：

- `?autostart=story` 或 `?autostart=free`：跳过标题页直接进入剧情或自由漫步。
- `?present=webgl`：在 Windows 上直接使用 WebGL 画布显示。

示例：`http://127.0.0.1:5173/?autostart=free`。
