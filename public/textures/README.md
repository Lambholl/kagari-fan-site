# 月球贴图

`moon-lroc-2048.jpg` 用于天空中的月球，分辨率为 2048×1024，采用经纬度展开，中央为月球 0° 经线。

- 来源：[NASA SVS — CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/)，2025 年版 LROC 月面颜色图。
- 原文件：[lroc_color_2k.jpg](https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg)
- 下载日期：2026-11-12
- 图片署名：NASA's Scientific Visualization Studio；可视化作者 Ernie Wright。数据来自 LRO 的 LROC 月面拼接图，极区由 LOLA 数据补充。
- 使用说明：[NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)

图片保留下载时的像素和颜色。场景按 sRGB 读取图片，将月海和陨石坑纹理用于月面的自发光，并叠加柔和的外缘光晕与 Bloom 辉光。球体朝向、大小和亮度由场景代码控制。文件随网站一起打包，游玩时不从 NASA 网站加载。
